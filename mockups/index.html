What counts as a pass
• Only scores of 9/10 or better are kept as test passes.
• 3 passes unlock that layer's Sailing Challenge.
• Passing the challenge unlocks the next layer.
• NA Political L2 challenge: 13 rounds, 3 misses allowed.
• All layers in a map type = new rank on that continent.
Also saved
• A test in progress, so you resume where you stopped
• Countries you keep missing, for extra practice
• Treasure codes collected

Optional: a copy-paste save code moves progress between devices without logins.
